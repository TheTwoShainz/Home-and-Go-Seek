🎲 Random House

Install the bookmark once. When you use it on Zillow, it asks for optional price and square-footage limits.

🎲 Random Zillow House
  1. Use the blue button to open Zillow.
  2. Scroll down to load multiple listings.
  3. Click the Random Zillow House bookmark.
  4. Enter price and square-footage limits.
  5. Leave any prompt blank for no limit.
